# Stage 3: API Testing & Endpoint Validation

## Overview
This section highlights technical backend testing capabilities using Postman to test RESTful APIs directly without a user interface[cite: 11]. It includes requests utilizing core HTTP methods, status code verifications, and security testing.

## Key Focus Areas
- **HTTP Methods:** Executing requests using `GET` (retrieve data), `POST` (send new data), `PUT` & `PATCH` (update existing data), and `DELETE` (remove data).
- **Status Code Analysis:** Validating response codes across categories, including `2xx` (success), `3xx` (redirection), `4xx` (client errors), and `5xx` (server errors).
- **API Security:** Distinguishing between **authentication** (verifying identity via credentials/tokens like `POST /api/login`) and **authorization** (checking permissions and roles).
- **Performance & Edge Cases:** Evaluating API response times, payload structures, and handling error states with positive and negative inputs.
