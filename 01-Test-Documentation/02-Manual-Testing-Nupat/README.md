# Stage 2: Manual Testing & Defect Management (Nupat Technologies)

## Overview
This section highlights the practical execution of manual and functional testing on web applications. It demonstrates the ability to execute test scenarios, analyze the complete bug life cycle, evaluate severity versus priority metrics, perform root-cause analysis, and provide clear test evidence and bug reports.

## Key Focus Areas
- **UI & Component Auditing:** Executing tests on Nupat Technologies web features—verifying information architecture, layout alignment, icons, and dynamic metric displays.
- **Defect Lifecycle Management:** Tracking bugs from discovery to closure, categorizing issues by severity and priority, and conducting root-cause analysis.
- **Test Evidence:** Gathering screenshots and execution logs to ensure developers can reproduce and resolve issues efficiently.
