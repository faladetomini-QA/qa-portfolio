# Stage 1: Test Documentation & Test Case Design

## Overview
This section showcases foundational QA skills and adherence to the Software Testing Life Cycle (STLC). It includes structured test cases designed to handle edge cases, verify system behavior against requirements, and maintain full traceability.

## Key Focus Areas
- **Verification vs. Validation:** Understanding the critical distinction between evaluating work products against standards ("Are we building the product right?") versus dynamic execution to satisfy business needs ("Are we building the right product?").
- **Test Design:** Crafting structured positive and negative test cases to cover standard and edge-case scenarios effectively.
- **Test Artifacts:** Documenting test scenarios, test conditions, and requirements trace frameworks.
